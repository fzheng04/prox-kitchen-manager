# Seed data

`seed.json` is generated by `npm run seed` (`scripts/generate-seed.js`). The output is deterministic: no randomness and no clock reads. All names, brands, prices and ZIP labels are synthetic. Types live in `src/logic/types.ts`.

Counts: 93 products across 3 retailers, 27 catalog items, 15 pantry items, 3 lists, 2 profiles, 2 ZIPs, 6 past trips.

How the app uses it: a first launch loads everything here: the catalog, the 2 profiles, 15 pantry items, 3 lists and 6 past trips (`initialState(id)`, scenario `sample`). Trips → "Start empty" clears the pantry, lists and history (scenario `fresh`) and Trips → "Reset demo" brings the seed back.

## Records

| Key | Shape | Notes |
|---|---|---|
| `seedNow` | ISO string | Start of the mock clock (Mon Jan 5 2026, 09:00 UTC). |
| `zips[]` | `{ code, label }` | `94110`, `94612`. |
| `retailers[]` | `{ id, name, short, priceFactor, zips[] }` | `priceFactor` was only used to generate prices. |
| `items[]` | `{ id, name, category, unit, terms[] }` | Canonical items. `unit` is the default list and pantry unit. |
| `products[]` | `{ id, retailerId, itemId, brand, name, size, unit, organic, priceCents, priceUpdatedAt, zips[], special? }` | `priceCents: null` means the price feed is missing. `special: { priceCents, endsAt }` applies only before `endsAt`. |
| `pantry[]` | `{ id, itemId, quantity, unit, dailyUse, lowThreshold, updatedAt }` | `quantity` is measured at `updatedAt`. Current stock is `quantity − dailyUse × days elapsed`. |
| `lists[]` | `{ id, name, revision, items[] }` | List item: `{ id, itemId \| null, text, quantity, unit, pinnedBrand?, organic? }`. `itemId: null` means it still needs a manual match. |
| `profiles[]` | `{ id, name, organicCategories[], pinnedBrands{itemId: brand}, favoriteItemIds[], discoverCategories[], dismissedProductIds[] }` | |
| `history[]` | `{ id, retailerId, completedAt, lines[{ itemId, quantity, unit }], totalCents, savingsCents, source }` | Used for usual-restock timing. |

Units: `fl_oz`, `qt`, `gal`, `ml`, `l` (volume), `oz`, `lb`, `g`, `kg` (weight), `ct`, `dozen` (count). Money is always integer cents.

## Deliberate edge cases

- **Same amount, different packaging:** 1 gal of whole milk at FreshCo, 128 fl oz at ValueMart. Greenleaf only sells 64 fl oz, so a gallon takes 2 packages.
- **Missing items:** ValueMart has no avocados, coffee or Greek yogurt. Greenleaf has no oat milk.
- **Missing price:** ValueMart olive oil (`priceCents: null`).
- **Expired special:** FreshCo eggs (ended the day before `seedNow`). **Active special:** FreshCo pasta.
- **Stale prices (older than 7 days):** Greenleaf rice (12 days) and coffee (9), ValueMart chicken (10), FreshCo organic frozen berries (15).
- **Not comparable:** Greenleaf honey is sold in fl oz, but the item is measured by weight.
- **Duplicate feed row:** FreshCo lists Field Day bananas twice at different prices.
- **ZIP-limited:** Greenleaf chicken and ground beef, and FreshCo avocados, are only in `94110`.
- **Brand conflict:** the organic-first profile pins Hillside peanut butter, and Value Pick is cheaper.
- **Organic variants** for spinach, milk, eggs and berries.
- **Ambiguous list entries:** "milk" and "yogurt" in Breakfast restock.
