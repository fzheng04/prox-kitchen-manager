Lucide icon (2px stroke, currentColor) fetched once from the lucide-static CDN and inlined as SVG; use for every glyph in Prox UI.
```jsx
<Icon name="shopping-cart" size={22} color="var(--text-on-dark)" />
```
- `name` is any lucide-static 0.460 name (kebab-case). Common: search, bell, users, package, filter, sliders-horizontal, receipt-text, shopping-cart, flame, chef-hat, user, plus, x, info, chevron-down, circle-arrow-right.
- `strokeWidth` overrides the 2px default.
